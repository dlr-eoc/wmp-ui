# Prettier
> Prettier is an opinionated code formatter [prettier.io](https://prettier.io/)
- The configuration file has been defined already: [prettierrc](../.prettierrc)
## IntelliJ
- Install [the official prettier plugin](https://plugins.jetbrains.com/plugin/10456-prettier)
- Navigate to Languagues & Frameworks > JavaScript > Prettier
- Select: "Automatic Prettier configuration"
- Run for files: ```**/*.{js,ts,jsx,tsx,cjs,cts,mjs,mts,vue,astro,html,scss}```
- Activate: Run on save, Run on pase, Prefer Prettier configuration to IDE code style
## VSCode
- Install [the official prettier plugin](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode)
