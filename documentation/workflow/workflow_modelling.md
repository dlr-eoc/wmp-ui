# Design Rules

## Element Positioning
### TLDR;
- Do not Position Elements overlapping it will result in non-clickable areas in the WMP-UI

### Overlapping
>![labelOverSequenceFlow](labelPositioning.png)
><br>The label is positioned over the sequence flow arrow.

> <br>
> ![labelInWMP_UI.png](labelInWMP_UI.png)
> <br> 
> - Always position Elements without overlapping
